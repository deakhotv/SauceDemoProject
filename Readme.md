# 🧪 SauceDemo Automation Tests

Complete automation test framework for SauceDemo website with Python, Selenium, and pytest.

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run all tests
python run_tests.py

# Run individual tests
pytest tests/test_q1_locked_user.py -v
pytest tests/test_q2_standard_user.py -v  
pytest tests/test_q3_performance_user.py -v
